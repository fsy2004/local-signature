# 本地手写签名

手机、平板和电脑打开网页即可签名，导出便于放入表格的白底或透明 PNG。无需注册；笔迹只在浏览器内存中处理。

**在线使用：https://fsy2004.github.io/local-signature/**

也可以下载 `index.html` 后用浏览器打开，离线使用。网页是一个自包含 HTML，CSS 和 JavaScript 均内联，无 CDN、框架、字体下载或后端。

## 使用

1. 用手指、鼠标或手写笔在画布内书写；手机可以横屏后使用“专注书写”。
2. 可调整笔粗和颜色，撤销或恢复整笔。“仅手写笔”适合浏览器能识别的主动笔；普通电容笔请关闭此选项。
3. 默认自动裁去空白并保留边距，导出宽度为 1600 像素；关闭裁边后导出完整画布，宽度至少 1600 像素。默认白底预览、白底导出；“显示白底”只改变预览。“导出透明背景”选项单独控制 PNG 背景，适合叠放在已有文档上。
4. “导出保存”在手机优先尝试系统文件分享，在电脑下载 PNG；不支持分享时降级为下载和图片预览，也可长按图片保存。“分享”分享图片文件，目标应用由操作系统提供。

复制图片需要浏览器权限。微信、QQ 内置浏览器若限制下载或分享，可从右上角菜单选择“在浏览器中打开”。网页不能保证把图片直接写入相册；首次打开链接需要网络，加载完成后可断网继续使用，离线重新打开请保存 HTML。

## 隐私

- 无签名上传接口、分析脚本、Cookie 或本地存储；刷新、关闭会丢失未导出的签名。
- CSP 禁止页面发起网络连接；没有外部运行时资源。
- GitHub Pages 托管网页，网页访问仍经过 GitHub 服务；签名点数据不会发送给托管服务。
- 导出或主动分享后的图片由用户选择的文件系统或应用管理。本工具不验证身份，也不提供数字签名证书。

## 源码与验证

`index.html` 是唯一运行时入口。JavaScript 按绘制、输入事件、历史、裁边导出与系统分享分段。界面缩放时按固定坐标重绘笔迹，完成的笔画使用离屏缓存，撤销历史不保存全画布位图。

`SOURCE_REVIEW.md` 记录下载审读过的开源项目、固定提交、具体函数和采用或不采用的理由。此版本没有捆绑第三方 JavaScript 库。

`tests/browser.cjs` 使用 Playwright 检查桌面、手机、平板视口、触屏输入、透明 PNG、裁边、撤销恢复、旋转、下载、专注模式、手写笔过滤、复制失败和分享降级。需要已有 Node.js、Playwright 和 Edge：

```powershell
node tests/browser.cjs
```

可通过 `PLAYWRIGHT_MODULE` 指定已安装的 Playwright 模块，`BROWSER_CHANNEL` 选择浏览器通道，`TEST_URL` 验证发布地址，`QA_DIR` 指定临时证据目录。测试不安装依赖。系统分享以 mock 验证接口边界，不能代替 iOS/Android 相册、微信、QQ 的真机测试。

## 部署

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保持纯静态文件服务。修改 `index.html` 后推送到 `main`，等待 Pages 部署完成。没有构建步骤。
